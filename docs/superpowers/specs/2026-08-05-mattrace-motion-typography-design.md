# MatTrace 动效与正文可读性升级设计

## 目标

在不改变 MatTrace 现有信息架构和功能逻辑的前提下，将界面升级为更活泼、更有展示感的科研 Agent，同时解决侧栏字体明显大于正文、正文阅读密度偏高的问题。

## 视觉原则

- 动效服务于状态、层级与操作反馈，不遮挡内容，不改变布局尺寸。
- 主要动画使用紫色、薄荷绿等现有品牌色，保持材料科研产品气质。
- 悬浮反馈明显但短促；持续动画低频且只用于机器人、状态点和背景装饰。
- 所有新增动画必须在 `prefers-reduced-motion: reduce` 下关闭或降为瞬时状态。

## 动效层级

### 机器人与侧栏

- 机器人以 3.6 秒周期上下浮动并轻微左右摆动，阴影同步缩放，形成悬浮感。
- 机器人背景光晕缓慢呼吸，手写标语轻微漂移。
- 鼠标经过机器人区域时，机器人向鼠标方向感知式倾斜并略微放大；不追踪精确鼠标坐标，避免增加脚本复杂度。
- 导航按钮悬浮时向右移动并上抬，背景渐变、边缘光晕与图标弹性放大同步出现。
- 当前导航项增加低频光泽扫过效果，但文字始终保持清晰。

### 正文与卡片

- 上传区、概要卡片、提醒卡片、证据区、导出卡片和会话卡片增加上浮、阴影扩散与边框提亮。
- 概要卡片的图标在悬浮时弹性旋转或缩放，数值轻微上移。
- 上传区的上传图标持续低频漂浮；拖入文件时切换为更明显的脉冲状态。
- 表格行在悬浮时使用轻微横向位移和渐变底色，突出可点击性。
- 进度节点的活动状态增加呼吸光圈，已完成节点之间显示轻微流动的连线高光。
- 顶部背景装饰进行缓慢漂移，不抢占标题阅读注意力。

## 字体与信息层级

- 正文基础小字号整体提升约 2px，不放大品牌标题和左侧主要导航文字。
- 区块说明文字从 10–12px 提升到 12–14px。
- 表头和表格内容分别提升到约 11px 与 12px，并增加行高。
- 证据引用提升到 13px，来源、条件和提示信息不低于 11px。
- 概要卡片标签提升到 10px，数值保持突出。
- 按钮、文件卡片、提醒卡片和会话说明同步放大，避免局部字号失衡。
- 桌面端优先提升；移动端通过现有媒体查询控制，避免文字放大造成横向溢出。

## 实现范围

- 主要修改 `app/MatTraceDashboard.css`，保持功能组件和状态逻辑不变。
- 只在需要稳定挂载动画的区域补充少量语义 class，不引入动画库或运行时依赖。
- 使用 CSS transform、opacity、filter 和 box-shadow，避免触发布局重排。
- 不增加粒子系统、Canvas、WebGL 或鼠标坐标追踪。

## 验收标准

- 机器人在静止页面中持续自然浮动，悬浮时有更明显反馈。
- 七个侧栏入口均有一致、明显、不卡顿的悬浮状态。
- 主要可交互卡片、上传区、表格行和进度状态均有视觉反馈。
- 正文、表格、说明、证据和按钮文字比当前版本明显更易读，且不出现截断或新增横向页面溢出。
- 桌面与 390px 移动端布局均通过浏览器测试。
- `prefers-reduced-motion` 下持续动画与过渡被关闭。
- 单元测试、Lint、开发版 E2E 与静态版 E2E 全部通过。

## 非目标

- 不改变现有功能、数据流、API 请求或导出格式。
- 不重新设计页面结构或替换机器人图片。
- 不为纯装饰加入 JavaScript 状态管理。
