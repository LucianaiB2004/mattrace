# Uplift 评测协议

对同一组 3–10 篇材料文档分别运行裸模型和挂载本 Skill 的模型。两组使用相同模型、温度、上下文和输出 Schema，各运行 3 次。不得把示例输出当作实测分数。

## 客观评分

使用 `scripts/score-uplift.mjs` 将输出与人工复核金标准逐字段比较。默认字段为材料规范名、性能名、规范化数值、规范化单位、来源文档和页码；数值采用 2% 相对容差，其余字段规范化大小写与空白后精确匹配。单次得分为匹配字段数除以金标准字段总数，范围为 0–1。

分别计算三次裸模型分数和三次 Skill 分数的中位数：

`uplift = median(skill_scores) - median(baseline_scores)`

记录模型名称、版本、温度、时间、输入文档哈希、三次原始输出和评分器版本。若任一组不足 3 次，不发布 uplift。

汇总六次已经客观评分的结果：

```bash
node scripts/score-uplift.mjs --baseline 0.30,0.28,0.31 --skill 0.74,0.76,0.75
```

命令中的数字必须来自真实运行；文档中的数字仅说明参数格式。

## LLM 评审

科学可信性、创新性等非离散维度使用 0 / 1 / 3 / 5 锚点，可取小数。要求评委逐项给出引用证据，LLM 分数与客观字段分数分开报告，不相加伪装为准确率。
