# 失败案例与科学边界

| 场景 | 必须输出 | 禁止行为 |
|---|---|---|
| 扫描 PDF 无文本层或 OCR 乱码 | `failed`，说明需要 OCR/人工复核 | 猜测页码或数值 |
| 全文无定量材料性能 | `no_evidence`，列出真实检查页 | 静默省略文档 |
| 模型响应截断或 JSON 无效 | `failed`，保留文档并允许重试 | 使用半截 JSON |
| 数值只有范围、上限、下限或约数 | 保留 `value_raw`，规范化边界另列 | 改写为精确单值 |
| 单位维度未知或不可换算 | `normalized_value: null` 并进入复核 | 原值冒充规范化值 |
| 摘要与正文数值不同 | 分别记录来源层级，正文/表格优先复核 | 合并为一条“结论” |
| 温度、方法、方向、密度等关键条件不同 | 分入不同可比组 | 直接排名或报冲突 |
| 表格列头、脚注与数值跨区域 | 使用多个证据片段并标明单元格/脚注 | 把脚注套用到无关行 |

Skill 只构建可复查的数据资产，不替代材料实验、认证或工程选材结论。证据质量评分描述可追溯程度，不等于材料真实性概率。
