# MatTrace 证据覆盖与可比性审计设计

## 目标

将真实分析从“所有文档混入一次请求并只返回一条代表记录”升级为用户选择 1–20 篇文档、逐篇完整提取、再做跨文献汇总的证据覆盖与可比性审计流程。Skill 规则必须真实进入模型提示词，而非仅用于页面展示。

## 工作区与选择

- 工作区容量从 10 篇提高到 20 篇，支持 PDF、DOCX、TXT 和 Markdown。
- 上传与分析选择是两个独立状态，界面同时显示 `已添加 N/20` 与 `已选择 M 篇`。
- 新增全选和取消全选；载入公开论文后默认全部选中，新上传文档默认选中。
- 文档卡片主体继续打开预览；独立复选框控制是否参与真实分析。
- 删除、清空、项目恢复后自动清理不存在文档的选择；至少选择 1 篇才能开始分析。

## 分析架构

1. 对每篇选中文档加载完整分页文本并生成独立证据片段。
2. 使用最多 2 个并发请求逐篇调用模型，避免多文档截断和网关压力。
3. 每篇必须返回 `extracted` 或 `no_evidence`：前者包含全部合格记录，后者包含未提取原因和已检查页码。
4. 合并全部单篇记录后，在浏览器领域层完成单位、条件、缺失字段和冲突核验；不允许某篇被静默遗漏。
5. 取消操作终止当前及未开始请求，并保留已有文档和选择。

模型提示词不再要求“最有代表性的 1 条”，而是要求抽取该文档中所有满足证据合同的材料性能记录。单篇响应上限提高，以容纳多条记录。

## Skill 真实运行

- 运行时提示词包含与仓库 `SKILL.md` 同源的核心合同：独立证据记录、页码引用、缺失不补写、单位保留、可比性分组、可信度上限和人工复核规则。
- `SKILL.md` 输入范围表述为“支持 1–20 篇；官方推荐任务规模 3–10 篇”。
- Skill 名称定位升级为 `Material Evidence Coverage & Comparability Auditor`，保留目录名 `material-evidence-extractor` 以避免现有引用失效。

## 差异化输出

### 覆盖矩阵

每篇选中文档生成：

- `document_id`、文档名与页数
- `status`：`extracted`、`no_evidence`、`failed` 或 `cancelled`
- 提取记录数
- 已检查页码
- 缺失条件数
- 需要人工复核的记录数
- 未提取或失败原因

页面展示覆盖率：已获得明确分析结论的文档数 / 选中文档数。

### 可比性护照

每条记录增加：

- 材料、属性、原值/单位与规范化值/单位
- 测试方法、温度、压力、频率、样品形态、方向和密度状态
- `comparability_group`
- `comparable` 与不可比原因
- 来源页码、证据原句和可信度

### 四维评分

- 证据覆盖率
- 条件完整度
- 来源可复查度
- 跨文献可比度

评分必须由记录字段确定性计算，不采用模型自报分数。

## 导出

现有 JSON、CSV、Markdown 报告继续保留，并增加：

- `coverage-matrix.csv`
- `comparability-passports.jsonl`

Skill 文件夹的示例、字段规范和核心代码同步包含这两个新交付物。

## 错误与恢复

- 单篇失败不会丢弃其他已成功文档；覆盖矩阵明确标记失败原因。
- 全部文档均失败时整个分析失败；部分成功时生成报告并提示存在待重试文档。
- `no_evidence` 是有效审计结论，不按错误处理。
- API Key 不进入提示词、报告、覆盖矩阵、Skill 或项目快照。

## 验收

1. 可上传最多 20 篇，第 21 篇给出明确容量错误。
2. 可选择任意 1–20 篇；模型请求只包含选中文档。
3. 选择三篇公开论文时产生三个独立请求，覆盖矩阵包含三篇且无静默遗漏。
4. 提示词包含 Skill 核心合同且不再要求仅返回一条记录。
5. 真实网关运行完成后，每篇都有 `extracted`、`no_evidence` 或明确失败状态。
6. 页面展示覆盖矩阵、可比性护照和四维评分。
7. 新增导出可下载并与页面数据一致。
8. 单元、动态端到端、静态端到端、Lint 和凭证扫描全部通过。

## 非目标

- 不让 Agent 无限制自主翻页或无限重试。
- 不在本轮加入向量数据库、账户系统或云端任务队列。
- 不更改现有 Skill 目录名。
